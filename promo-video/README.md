# TEN10 brand film (promo video)

A ~115-second product-brand film for TEN10. It comes in two independent language versions (Hebrew RTL / ₪, English
LTR / $), each in landscape (1920×1080) and vertical (1080×1920).

The film is **frame-accurate canvas motion graphics** (`film/geo.js`). It is a web page whose every frame is a pure
function of time `t`. Headless Chromium seeks it frame by frame and ffmpeg encodes the frames. The Python tools in
`tools/audio/` make the narration (ElevenLabs v4), the score and the UI sound design, and mix them.

It uses the product's own brand sources, with nothing redesigned:

| Source | Used for |
|---|---|
| `public/logo/logo-wide.svg`, `logo.svg` | The ring's position and thickness when it becomes the logo's "0". They are measured once from the SVGs, so the wordmark and the stacked logo grow out of the ring exactly. |
| `public/fonts/Assistant-VariableFont_wght.ttf` | All typography, Hebrew and Latin. It is the app's own font. |
| `lucide-static` (the app's icon set) | Every icon (`film/icons.js`, generated by `npm run icons`) |
| `public/locales/{he,en}/*.json`, landing copy | The on-screen strings, collected in `film/content.js` |
| `public/halacha/machon-semel.png` | The institute's emblem (upscaled ×3 into `film/assets/`) |

## Quick start

```bash
cd promo-video
npm install                              # playwright-core (uses the system Chromium) + lucide-static
pip install numpy scipy imageio-ffmpeg   # audio tools; imageio-ffmpeg only if ffmpeg isn't on PATH

npm run preview                          # → http://localhost:5178/promo-video/film/?lang=he  (scrub / space = play)
node tools/stills.mjs --lang he --sheet 48       # contact sheet → renders/stills/he_sheet.png
node tools/stills.mjs --lang en --t 9.7,21.7     # single frames
node tools/stills.mjs --lang he --times          # print every resolved scene/beat time
node tools/stills.mjs --lang he --qa             # how long every on-screen line is fully legible

tools/produce.sh he audio/narration_he.wav       # full production synced to the recording
FORMAT=vertical tools/produce.sh he audio/narration_he.wav   # the 9:16 version
MUSIC=audio/licensed.wav tools/produce.sh en audio/narration_en.wav   # with a licensed music track
tools/produce.sh he                              # no recording yet: provisional (estimated) timing
```

Output is `renders/<lang>/TEN10_promo_<lang>_1080p.mp4` or `renders/<lang>-vertical/TEN10_promo_<lang>_vertical_1080x1920.mp4`.
Both are 30 fps, H.264 High CRF 16 with AAC 256k, at −16 LUFS / −1.5 dBTP with narration.
A render takes about 5–10 minutes per version with 4 parallel browsers (`WORKERS=4`).

If Chromium lives somewhere unusual (on Windows, for example), set `CHROMIUM_PATH` to Chrome or Edge. If ffmpeg isn't on
`PATH`, set `FFMPEG`; otherwise the tools fall back to imageio-ffmpeg.

## The narration is the master timeline

Nothing in the film is timed in absolute seconds. `narration/script.<lang>.json` splits each script into 23 phrases
with stable ids (`hook1` … `free`). Each phrase has a `pauseAfter`. An optional `hold` adds a reading beat after a topic
has finished building on screen: the last frame of the topic stays put (silence in the voice-over) before the next one.
`narration/timing.<lang>.json` gives each phrase (and each word) a start and end. Every scene boundary and emphasis beat in
`film/geo.js` is derived from those anchors (`A.s(id)`, `A.e(id)`, `A.w(id, word)`). The keyword beats per language live in
`film/content.js → beats`; they are the narration words that trigger visuals. For example, the Chomesh ring appears exactly
when "חומש" / "Chomesh" is spoken.

**Making the narration (ElevenLabs v4 through fal.ai).**
- `tools/audio/tts_elevenlabs.py` synthesises each phrase on its own, trims it, and lays the phrases out with the script's
  pauses and holds into `audio/narration_<lang>.wav`. Takes are cached in `audio/tts/` by a hash of the request, so a re-run only
  pays for phrases that changed.
- It also writes `audio/narration_<lang>.spans.json` with the exact phrase edges. `produce.sh` passes these to
  `sync_narration.py` as overrides, so an expressive pause inside a phrase can't move a boundary.
- The voice reads `narration/spoken.<lang>.json` where it has an entry, and the on-screen text everywhere else:
  - per-phrase performance tags;
  - voice-only rewordings, which are allowed to differ from the screen;
  - Hebrew vowel points on the words TTS misreads (מַעֲשֵׂר, מְרַכֵּז);
  - English "Khomesh" and "Halakha", because "Chomesh" comes out as Chumash/Chometz.
- An entry can also be `{"text", "direction"}`, which replaces the global direction for that one phrase. The closing "Ten Ten"
  uses `[calm, assured, understated]`; under the energetic global direction it sounded hyped.
- Very short phrases sometimes come back with the word repeated, so check them with speech-to-text. To get a new take,
  delete the phrase's file in `audio/tts/<lang>/`.
- The chosen read for both languages is the voice "Omer":

```bash
FAL_KEY=... python3 tools/audio/tts_elevenlabs.py --lang he --fal --voice k77ZRVqAFg9Hd0ltAuON --stability 0.35 \
    --spoken narration/spoken.he.json --direction "[upbeat, warm, confident, energetic]"
FAL_KEY=... python3 tools/audio/tts_elevenlabs.py --lang en --fal --voice k77ZRVqAFg9Hd0ltAuON --stability 0.35 \
    --spoken narration/spoken.en.json --direction "[upbeat, warm, confident, energetic]"
```

v4 has no SSML, style or speed controls; direct the read with tags. Avoid "smile"/"smiling" in tags, because v4 renders
them as a laugh. Without `--fal` the tool calls ElevenLabs directly (`ELEVENLABS_API_KEY`); library voices need a paid plan.

**A studio recording** works the same way: `tools/sync_narration.py` detects speech and silence and aligns the phrases to
the real pauses with dynamic programming. The audio is never cut, sped up or stretched; its t=0 is the film's t=0. Details,
the report format and manual overrides are in `tools/AUDIO.md`.

## The film: `film/geo.js`

It is one continuous shot on one canvas. The logo's ring (the "0") never leaves the screen. It moves between per-scene states
(`S.*` in `init`, blended by the keyframes in `keys()`), and its gold tenth is centred on the logo's own wedge.

| Scene | Anchors | What happens |
| --- | --- | --- |
| hook | hook1, hook2 | the ring draws itself; the tenth drops into its slot: 10% (eyebrow "מעשר כספים") |
| chaos | complex1 keywords, complex2 | each spoken keyword lands with its real fragments, which orbit the ring faster and faster |
| order | order | everything spirals in; the ring becomes the "0" of the wordmark; the app's badge line |
| maaser | maaser, chomesh, currency | the ring is the income, its tenth the maaser; an inner ring's 20% the chomesh; 1,000 + 400 − 580 = 820; currencies convert on the way in |
| hebrew | hebrew | the app's display-calendar switch flips to Hebrew; the months around the ring become a 13-month Hebrew year; a period, then the maaser year |
| import · recurring · reminders · analytics | import … analytics | spool · self-filling year · dark wipe and the reminder email · the pour into columns |
| budget · insights | budget, insights | cash flow, income vs. expenses and savings rate, with insights for the period |
| reports | print, Excel | the baseline becomes a printer slot, the report rises, the ring lands as its logo; Excel / PDF / CSV |
| not just numbers | numbers | the report's numbers lift off and scatter |
| halacha | Halacha Library | an open book; topics rise into a list; the ring becomes a lens and finds chomesh |
| rabbi | question, Ask | the lens becomes a speech bubble: "?", the button, the message, sent |
| trust | Institute, rabbis | the ring frames the institute's emblem; partnership and endorsement lines, verified badge |
| platforms | web, desktop, offline | web and desktop windows drawn in the same geometry; the ring becomes a globe; offline badge |
| together | income, donations, obligations | every motif of the film orbits back; the ring splits into the three, named inside it |
| end | brand, tagline, free | the stacked logo grows out of the ring; halo; tagline; free; URL; institute credit |

All copy comes from `content.js` (`copy.cine.big` sets which narration words are set large per phrase). Words appear as
they are spoken, and each block stays until the next phrase begins.

**The ending** is the call to action. The address is a gold pill. Two cards flank it: a QR to the landing page and the
institute's emblem. The QR (`film/assets/qr-ten10-app.svg`) opens
`https://ten10-app.com/landing?utm_source=promo-video&utm_medium=qr`, so visits from it show up in PostHog under
`utm_source = promo-video`. To change the address, regenerate it with the `qrcode` package and recolour it:

```bash
python3 -c "import qrcode, qrcode.image.svg as s; q = qrcode.QRCode(error_correction=qrcode.constants.ERROR_CORRECT_M, border=1, image_factory=s.SvgPathFillImage); q.add_data('https://ten10-app.com/landing?utm_source=promo-video&utm_medium=qr'); open('film/assets/qr-ten10-app.svg', 'w').write(q.make_image().to_string(encoding='unicode'))"
# then set width/height="540", fill="#0c4a4c" and shape-rendering="crispEdges" on the path
```

Check that it still scans from a rendered still (`stills.mjs`) at half resolution.

The brand name is spoken as its logo finishes. Both logo builds (`order` and `brand`) start in the silence before the
name, set by `ORD_LEAD` and `BRAND_LEAD` in `geo.js`. The pause before `order` (`complex2.hold`) is long enough for a beat to
read "harder to keep track", then the ~1.85 s build.

**Localisation.** Hebrew is authored first (RTL), and English is mirrored and then rebalanced. Hebrew text is animated
only by words and lines, never letter by letter, so shaping is never broken. Amounts use `Intl.NumberFormat` (`he-IL`/ILS,
`en-US`/USD) like the app. Hebrew dates come from `Intl` with the Hebrew calendar. In English, the month names are respelled
to the usual Jewish-English forms (Tishrei, Cheshvan, Tammuz; `content.js → cal.spell`).

**Vertical** (`?format=vertical`, `--format vertical`, `FORMAT=vertical`) is its own composition, not a rotation. Timing,
scenes and sound are shared, and the layout branches on `V` in `geo.js`. Shorter cuts can reuse the same anchors: record a
narration with a subset of the phrase ids and guard the missing scenes with `A.has(id)` (in `engine.js`).

## Sound

- **Score:** `tools/audio/synth_drive.py` is energetic (~122 BPM): four-on-the-floor kick, claps, 16th hats, pumping bass
  and a supersaw pad side-chained to the kick, a pluck arpeggio, and risers and impacts into the logo reveal and "brand".
  - It reuses the grid, harmony and narration-following sections of `tools/audio/synth_music.py`.
  - `synth_music.py` also makes the earlier calm bed (`MUSIC_GEN=synth_music.py`).
  - Pass `MUSIC=path.wav` to `produce.sh` to use a licensed track.
- **Ducking:** a real sidechain from the narration (−9 dB, 80 ms attack / 450 ms release). Without narration (preview), the
  key comes from the timing's phrase spans and the dip is only 3 dB, so the preview still lets you judge the score.
- **UI sounds:** tap, tick, arrive, whoosh, sweep, calendar, notify, resolve, pop and type (`tools/audio/synth_sfx.py`).
  `geo.js` places them itself (`cue(t, type, gain)`), and the render exports them to `renders/<lang>/sfx-cues.json`.
- Details and loudness targets: `tools/AUDIO.md`.

## Known limitations

- The institute's logo exists in the repo only as a 145×109 PNG. The film upscales it ×3, which holds up at the displayed
  size, but a vector or high-resolution original would be sharper.
- The score is procedural. It is fine for release review, but a licensed track may be preferred.
- Word-level beats inside a phrase are letter-proportional (snapped to micro-pauses in the recording). They are accurate
  enough for emphasis but not for lip-sync. Use `narration/timing.<lang>.overrides.json` to nudge any beat.
