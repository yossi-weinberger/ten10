# TEN10 — narration scripts (voice-over)
Pauses (seconds) are directions for the read. Lines may differ from the on-screen text on purpose (voice-only rewordings); the synthesized narration reads the same wording from narration/spoken.<lang>.json, which adds vowel points and v4 performance tags. The Hebrew "recording" version spells TEN10 as טֶן טֶן and points חוֹמֶשׁ so TTS reads it correctly. "hold" is an extra still beat after a topic finishes on screen: leave it as silence (tools/audio/tts_elevenlabs.py inserts it automatically).
